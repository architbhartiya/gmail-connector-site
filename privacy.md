# Privacy Policy: Personal Gmail Reader (Claude Connector)

Last updated: 1 November 2026

This app is a personal tool used only by its owner, Archit Bhartiya, with his own Google account.

**What it accesses.** With the owner's permission, it reads Gmail messages, threads, labels and attachments,
and creates drafts.

**What it stores.** The Google sign-in token is stored only on the owner's computer, in `~/.config/gmail-mcp/`.
Email content is not saved by the app.

**Who it shares data with.** Nobody. The app has no server and does not send Google user data anywhere except
to the owner's own AI assistant session running on the same computer.

**What it never does.** It does not send, reply to or delete email. It does not sell data, use it for
advertising, or let people read it.

**Google API Services.** The app's use of information received from Google APIs follows the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

**Revoking access.** The owner can remove access at any time at https://myaccount.google.com/permissions.
